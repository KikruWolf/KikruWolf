## Thesis — Memetic Genetic Compiler for Approximate Quantum State Preparation

Graded **90, the only A+ awarded in my faculty.**

A **memetic genetic algorithm** that compiles approximate quantum circuits for state preparation on near-term hardware:

- Circuit synthesis via evolutionary search with local optimisation
- Benchmarked against exact synthesis (Qiskit SBM) and LRSP across GHZ, W, Gaussian and Haar-random state families
- Evaluated on IBM Fez (156-qubit heavy-hex) under realistic noise
- A hybrid fitness function balancing noiseless fidelity against noisy hardware performance
